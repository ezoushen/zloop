# Small work finishes without an interview or confirmation

When `autopilot <goal>` cuts into one or two tickets with nothing on the pause list and no material question, the run asks the user nothing: no interview and no run-card confirmation, its card recording a confirmation by rule from the goal the user typed. It still keeps the required checks and one independent review at the lowest level, and a third ticket, a pause-list action or a material question switches it to the full path and the user's confirmation, so only the ceremony is dropped, never the floor of ADR 0015.

## Considered Options

- The full path for every goal: an interview and a confirmation round cost more than a one-ticket change.
- No review for small work: rejected by the user; every level keeps an independent review.
