# A worker counts only with its own session record

A worker attempt counts only when its own session record proves it ran: startup settings are read from the record, never typed by the host, and a result is collected only when the record holds the packet's `attempt:` line followed by the worker's reply (a Codex native child, whose packet is encrypted, by its parent link, a name derived from the attempt and a reply). A review cannot end without its configured reviewer: the stop hook holds the session until the report names a completed, collected diff-review attempt at the reviewed head, or records a blocker after a reviewer launched at that head settled without completing, or records local review or a blocker where no reviewer route exists. We chose script enforcement over procedure wording after hosts reviewed inline and registered workers that never ran; a deliberately forged record still passes, which only signing could stop.
