# Executor guides

A route names its guide by executor type:

- [subagent](subagent.md): a native child agent.
- [herdr](../herdr.md): the built-in provider, a worker in a Herdr tab of its own.
- [t3](../t3.md): the built-in T3 Code route, a worker in a T3 thread of its own, selected by configuration.
- [skill](skill.md): an external skill.
- [bash](../../runtime/config/bash-executor.md): a configured program that follows the assignment and result contract.
